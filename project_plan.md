# Создание платформы для архива стримов Hyver (Итоговый план)

## Описание цели
Разработка современного веб-приложения для хранения и просмотра записей стримов с Twitch-канала [Hyver](https://www.twitch.tv/hyver). 
Визуальный стиль, дизайн, микро-взаимодействия и анимации будут вдохновлены сервисом [Streamhound](https://ru.streamhound.app/) (глубокие темные тона, стекломорфизм, неоновые акценты, шрифты Montserrat, динамичные графические элементы). 
Функциональная концепция заимствуется у [Архива BlackUFA](https://bsu.drhx.ru/) — это каталог видеозаписей с продвинутым плеером.

## Выбранные технологии и архитектура
- **Фронтенд и Бэкенд (Fullstack):** Next.js (React).
- **Стилизация:** Tailwind CSS + кастомные классы для стекломорфизма и градиентов.
- **Анимации:** Framer Motion (для достижения максимальной плавности UI).
- **Хранилище видео:** Приватный Telegram-канал.
- **Технология стриминга:** FFmpeg для нарезки оригинального VOD на HLS-чанки (`.m3u8` и `.ts`), с последующей загрузкой чанков в Telegram и отдачей их через Next.js API Routes.

## Этапы реализации

### Этап 1: Поиск скиллов и решений на GitHub
- Исследование и подбор на GitHub готовых библиотек для UI (например, продвинутые видеоплееры на базе React, компоненты glassmorphism).
- Поиск существующих OpenSource решений для организации прокси-сервера потокового видео через Telegram (поиск аналогов `tg-video-streaming` для работы с HLS).

### Этап 2: Проектирование архитектуры и дизайна
- Инициализация проекта Next.js + Tailwind.
- Создание системы дизайна (цвета, шрифты Montserrat, градиенты, эффекты).
- Разработка UI каталога записей (карточки стримов с датами, играми, статистикой).

### Этап 3: Разработка бэкенда и Хранилища
- Создание скрипта-обработчика (Node.js + FFmpeg): скрипт принимает VOD, конвертирует в разные качества (1080p, 720p), нарезает на HLS чанки и отправляет в Telegram.
- Разработка API (Next.js API Routes) для безопасного стриминга видео из хранилища Telegram (MTProto / Bot API) в плеер клиента без раскрытия токенов.

### Этап 4: Разработка мощного видеоплеера
- Интеграция плеера (Plyr-React или Video.js).
- Подключение `hls.js` для поддержки бесшовного переключения качества видео (Auto, 1080p, 720p, 360p).
- Реализация функционала безопасного скачивания исходного видео.

### Этап 5: Сборка, тестирование и деплой
- Интеграция всех компонентов воедино.
- Анимация переходов между страницами (Framer Motion).
