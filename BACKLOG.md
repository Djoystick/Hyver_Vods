# VOD Hyver Roadmap / Backlog

1. **VK Video Integration:** Реализовать автоматическую заливку записей во ВКонтакте в качестве резервного (дополнительного) источника.
2. **Продолжить просмотр:** Сохранение прогресса видео в `localStorage` и отображение на главной странице.
3. **Глобальный поиск по таймкодам:** Сделать `timecodes.json` глобальным и добавить поиск конкретных моментов по всем VOD'ам с перемоткой.
4. **Избранное:** Добавить кнопку "Сердечко" для локального сохранения любимых стримов в отдельный список/вкладку.
5. **Клипы/Хайлайты:** Отдельный раздел сайта с короткими смешными моментами (30-60 сек) с загрузкой из Telegram API.
6. **Фильтр по играм:** Сетка обложек игр (как на Twitch) для фильтрации VOD'ов, содержащих эту игру.
7. **Статус "В обработке":** Добавление видео на сайт в статусе "В обработке" еще до окончания загрузки в Telegram.

8. **Twitch Chat Replay:** Интеграция реального чата со стримов. При выкачивании VOD через `TwitchDownloaderCLI` будет скачиваться `chat.json`, который на фронтенде будет синхронно прокручиваться вместе с видео.
9. **Таймкоды:** Отображение таймкодов под плеером. Парсинг будет происходить **автоматически из описаний VOD на YouTube/Twitch или из прямых трансляций Twitch**.

## Архитектура автоматизированного пайплайна (Целевое видение)

Полный цикл работы скрипта по окончании трансляции:
1. **Инициализация:** При запуске скрипта собираются метаданные нового VOD с Twitch.
2. **Создание карточки:** Моментально создается карточка на сайте в статусе "В обработке" со всеми базовыми данными.
3. **Скачивание:** Видео скачивается с Twitch локально на ПК.
4. **Скачивание чата:** Лог чата скачивается через `TwitchDownloaderCLI` в формат JSON.
5. **Параллельная обработка и бэкап:**
   - Начинается нарезка скачанного видео на HLS-чанки.
   - Параллельно запускается выгрузка цельного исходного видео в группу ВК (vkvideo.ru/@hyverttv).
   - Параллельно запускается выгрузка цельного исходного видео на YouTube (youtube.com/@HYVERTTV/videos).
5. **Синхронизация:** Скрипт дожидается завершения нарезки чанков и загрузок на резервные площадки (ВК и YouTube).
6. **Загрузка в Telegram:** Готовые чанки начинают выгружаться в базу Telegram.
7. **Финализация:** После успешной загрузки на все три источника, скрипт дополняет карточку видео на сайте ссылками (VK, YouTube, HLS-плейлист) и снимает статус обработки.
8. **Очистка:** Исходные видео и локальные чанки удаляются с ПК для освобождения места.
